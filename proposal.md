# Мини-трекер учебных задач на неделю

## Цель
Создать автономный мини-трекер, позволяющий добавлять и удалять
учебные задачи, менять статус выполнения и видеть прогресс по часам.

## Границы
- Данные задачи: id, title, hours, done.
- Добавление, удаление и переключение done изменяют данные.
- Проверка названия и часов с ошибками рядом с полями.
- Фильтр «активные» меняет только видимый список.
- Итоговые часы и прогресс вычисляются по всем задачам.
- Интерфейс читаем на ширине 390 px, без горизонтального скролла.
- Поля и кнопки подписаны.
- CDN, внешние библиотеки и API-ключи не используются.

## Варианты поставки
Вариант выбирается в отдельном запросе на реализацию:
- A: один tracker-v2.html с CSS и JavaScript внутри.
- B: index.html, styles.css, app.mjs, domain.mjs
  и tests/acceptance.test.mjs.

Поведение и правила расчёта одинаковы для обоих вариантов.

## Стартовый пример
| Название | Часы | Выполнено |
|---|---:|---|
| Чтение | 2 | Да |
| Практика | 4 | Нет |
| Повторение | 2 | Нет |

Начальные показатели: всего 8 ч, выполнено 2 ч, прогресс 25%.

## Необязательное улучшение
Сохранение задач в localStorage. При недоступном хранилище
показывается понятное сообщение, работа продолжается в памяти.

## Разделение этапов
Текущий этап — только спецификация. Код и реализация выполняются
отдельным запросом. Дополнительные функции в задачу не входят.
