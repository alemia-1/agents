# Данные и расчёты

## Модель
Задача содержит:
- id: уникальный стабильный идентификатор.
- title: строка, непустая после trim.
- hours: конечное число в диапазоне 0,5–24, кратное 0,5.
- done: логическое значение.

Состояние приложения:
- Полный массив задач — источник данных для всех расчётов.
- Выбранный фильтр: все задачи или активные.
- Текущие значения полей формы и ошибки проверки.

Стартовые задачи имеют разные id и значения из proposal.md.
Новая задача получает новый id и done=false.
Удаление и переключение выполнения адресуют задачу по id.

## Проверка ввода
1. Получить название и исходное значение поля часов.
2. Проверить непустоту названия после trim.
3. Проверить непустоту часов до преобразования в число.
4. Проверить, что всё значение часов представляет конечное число.
5. Проверить диапазон 0,5–24 включительно.
6. Проверить кратность 0,5: удвоенное число часов должно быть целым.
7. При ошибках сохранить введённые значения, показать ошибки
   рядом с полями и не изменять массив задач.
8. При успехе сохранить обрезанное по краям название и числовые часы.

## Расчёты
Общие часы = сумма hours полного массива задач.

Выполненные часы = сумма hours задач полного массива,
у которых done=true.

Прогресс:
- Если общие часы равны нулю — 0%.
- Иначе — округление до ближайшего целого
  (100 × выполненные часы / общие часы).
- При точной половине округление выполняется вверх.

Поскольку часы валидных задач положительны, нулевой итог
соответствует пустому массиву. Проверка нулевого итога выполняется
до деления, исключая NaN и Infinity.

Контрольные значения:
| Состояние | Всего | Выполнено | Прогресс |
|---|---:|---:|---:|
| Стартовый пример | 8 ч | 2 ч | 25% |
| «Практика» выполнена | 8 ч | 6 ч | 75% |
| Все задачи удалены | 0 ч | 0 ч | 0% |

## Фильтрация и обновление
Фильтр «активные» выбирает для отображения задачи с done=false.
Он не изменяет массив задач и не участвует в расчёте показателей.

После добавления, удаления или переключения done:
- Пересчитываются показатели по полному массиву.
- Обновляется список с учётом текущего фильтра.

## Интерфейс
Форма содержит подписанные поля названия и часов и кнопку добавления.
Для задач доступны переключение выполнения и подписанное удаление.
Ошибки расположены рядом с соответствующими полями.
Компоновка и перенос текста исключают горизонтальный скролл
при ширине 390 px.

## Организация вариантов
A:
- tracker-v2.html содержит разметку, стили и всю логику.

B:
- index.html — разметка.
- styles.css — стили.
- app.mjs — форма, события, отображение и состояние приложения.
- domain.mjs — проверка данных, операции с задачами и расчёты.
- tests/acceptance.test.mjs — автоматические проверки доменного
  поведения средствами встроенного тестового раннера Node.js,
  без внешних библиотек.

Для B проверки отображения и ширины экрана выполняются отдельно
в браузере. Доменные тесты не заменяют проверки интерфейса.

## Необязательное сохранение
Если улучшение выбрано, задачи сохраняются после успешных изменений.
При старте используется сохранённый список, если он доступен;
при отсутствии сохранения — стартовый пример.
Пустой сохранённый список не заменяется примером.

При ошибке доступа к хранилищу показывается понятное сообщение.
Текущее состояние остаётся в памяти и доступно для изменений.
